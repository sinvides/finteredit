# Переводы

Все сообщения мода хранятся в файлах `assets/finteredit/lang/*.json`.

Чтобы добавить язык:

1. Скопируйте `assets/finteredit/lang/en_us.json` под новым именем, например `de_de.json`.
2. Переведите значения. Ключи и `%s` менять нельзя.
3. Пересоберите мод командой `cargo horizon-mod build --wasm`.

Язык выбирается автоматически по языку клиента игрока. Если нужного файла нет, используется английский.
